> 主文档：`PRD-V2.md` | 版本：V1.0 | 日期：2026-04-30
> 对标竞品：句乐部（主要）+ 哇学社（参考）

## 一、页面概述

### 1.1 定位

`/practice` 是整个产品的**核心体验页面**，承载三层架构中的 Layer 1 — 引流/获客/激活。

用户打开 TypeNow 的第一印象取决于此页面：句乐部验证了「中译英逐词敲击」的上瘾性，TypeNow 要在体验细节上做到更好。

### 1.2 设计目标

| 维度 | 目标 |
|---|---|
| **第一印象** | 干净、专业、不浮夸。不像游戏，像一本精心设计的练习册 |
| **核心体验** | 全程键盘操作，手不离键盘；逐词敲击反馈即时且优雅 |
| **学习辅助** | 竞品已验证有效的辅助元素全配齐：音标、词性颜色、点击发音、快捷键提示 |
| **差异化** | 比句乐部更克制的视觉、更智能的辅助、更流畅的键盘体验 |

### 1.3 页面状态

| 状态 | 说明 | 触发条件 |
|---|---|---|
| **正常练习** | 用户在做题中 | 默认 |
| **暂停** | 用户点击暂停或切到后台 | 点击暂停按钮 / 窗口失焦 |
| **句子过渡** | 当前句完成 → 下一句之间的 0.5s | 自动触发 |
| **本轮结束** | 一轮（≥10 句）完成后跳转结果页 | 一轮完成 |
| **退出确认** | 用户按 Esc 或点击返回 | 主动退出 |

### 3.1 Top Bar（导航栏）

#### 3.1.1 布局

```
← 返回    [⏸ 暂停]              [连击 🔥×12]  [⭐ 328]  [👤]
```

#### 3.1.2 元素规格

| 元素 | 交互 | 说明 |
|---|---|---|
| **← 返回** | 点击 → 弹出退出确认 | 退回到 `/home`，如果本轮有进度则提示「当前进度将丢失」 |
| **⏸ 暂停** | 点击 / 按 `Space`（长按 1s）→ 暂停 | 暂停时整个练习区模糊，显示「已暂停，按空格继续」 |
| **连击数** | 纯展示，数字平滑过渡动画 | 累计连续 Perfect/Good 次数；Keep trying 时归零 |
| **分数** | 纯展示，数字平滑过渡 | 本轮累计分数 |
| **👤 头像** | 点击 → 弹出快捷菜单 | 菜单内容：个人主页 / 设置 / 退出登录 |

#### 3.1.3 连击数动画

```
正常状态：🔢 数字 + 🔥 emoji（小号，无火焰特效）
连击突破阈值（10/50/100）：数字放大 120% + 金色描边闪一下（300ms）
中断：数字缩小 → 归零 → 恢复默认大小
```

#### 3.1.4 暂停状态

```
暂停时：
- 整个 Main Area 被半透明遮罩覆盖（filter: blur(4px) / opacity 降低）
- 遮罩中央显示：⏸ 已暂停
- Bottom Bar 仍然可见但变灰
- 点击遮罩任意位置 / 按 Space：恢复
- 按 Esc：退出确认
```

### 3.4 Main Area — 语法结构条

> **灵感来源：句乐部的词性颜色标识 + 哇学社的语法结构解析。这是 TypeNow 的差异化亮点之一。**

#### 3.4.1 规格

```
位置：中文提示区下方 8px
高度：30px
默认显示：✅ 显示
可关闭：是（用户可在设置中隐藏）
```

#### 3.4.2 显示内容

将英文句子按主谓宾/词性分块，用不同颜色标识对应的中文：

```
┌────────────────────────────────────────────────┐
│ [主语·绿]  [状语·蓝]  [谓语·红]  [宾语·橙]       │
└────────────────────────────────────────────────┘

对应的英文分词着色（在已完成词展示区体现）：
I(绿色) yesterday(蓝色) went(红色) to the supermarket(橙色)
```

#### 3.4.3 词性颜色方案

| 词性 | 中文标签 | 颜色 | 色值（浅色模式） | 色值（深色模式） |

| 谓语/动词 | 动词 | 红色 | `#DC2626` | `#F87171` |

### 3.5 Main Area — 已完成词展示区

#### 3.5.1 规格

```
布局：水平排列，从右到左自然增长
词间距：词之间用 ▸ 分隔符（或空格，取决于用户偏好设置）
溢出处理：超过容器宽度时整体左移，最新完成的词始终可见
动画：新词出现 fade-in (150ms) + 从右侧滑入
```

#### 3.5.2 单词样式

```
已完成词：
  字体：18px，等宽/无衬线
  颜色：正确 → 词性对应颜色 + 下划线色条（2px）；自行纠正后正确 → 带波浪下划线
  背景：无背景（干净），或可选浅色底
  间距：词间距 8px

分隔符 ▸：
  颜色：#CBD5E1（非常淡，不干扰阅读）
  字号：14px
```

#### 3.5.3 三种单词状态

| 状态 | 视觉 | 触发 |
|---|---|---|
| **Perfect 词** | 词性配色 + 饱满色条底线 | 一次输入正确 |
| **Corrected 词** | 词性配色 + 波浪底线（蓝色） | 输错后 Backspace 修正正确 |
| **当前词** | 输入区中，有焦点样式 | 正在输入中 |

#### 3.5.4 单词交互

| 交互 | 行为 |
|---|---|
| **点击已完成词** | 发音（TTS 朗读该单词） |
| **悬停已完成词** | 显示 tooltip：音标 + 中文释义（可选） |
| **双击已完成词** | 无行为（避免误操作） |

### 3.6 Main Area — 当前输入区（核心交互）

#### 3.6.1 规格

```
位置：已完成词展示区右侧（跟随最后位置），或新起一行
宽度：自适应词长，最小 80px，最大 300px
高度：48px（单行输入）
字体：18px，等宽字体（monospace），与英文显示统一
输入框样式：
  默认：底部单 underline，宽度随输入增长
  错误状态：underline 变红色
  正确确认：underline 变绿色（闪一下 200ms 后恢复默认）
背景：透明
```

#### 3.6.2 输入框样式选项（设置中可切换）

| 样式 | 效果 | 对标 |
|---|---|---|
| **单下划线**（默认） | 仅底部 2px 线条，干净 | TypeNow 默认 |
| **自适应宽度框** | 宽度随词长变化，浅色背景 | 句乐部风格 |
| **固定宽度框** | 固定 200px 宽度 | 适合长词场景 |

#### 3.6.3 音标与释义辅助

> **灵感来源：句乐部 + 哇学社均有音标展示。这是提升学习效果的关键辅助。**

```
输入区下方（8px）显示两行辅助信息：

第 1 行：音标
  /ˈjestərdeɪ/
  字体：14px，serif（或 Doulos SIL 等音标字体）
  颜色：次要文字色（#94A3B8）

第 2 行：词性 + 中文释义
  adv. 昨天
  字体：13px
  颜色：#64748B
```

**显示时机：**

| 时机 | 行为 |
|---|---|
| 用户开始输入 | 实时匹配当前输入 → 显示匹配词的音标和释义 |
| 输入匹配失败 | 显示占位提示「...」 |
| 确认当前词后 | 音标和释义保留显示 1 秒后淡出 |
| 下一词开始输入 | 切换为新词的音标和释义 |

#### 3.6.4 实时输入匹配

```
匹配逻辑（不依赖 AI，纯规则）：
1. 用户输入字母时，在「当前词的标准答案」中进行前缀匹配
2. 如果完全匹配 → underline 保持默认色
3. 如果当前输入 ≠ 标准答案前缀 → underline 变红 + 微微抖动（150ms）
4. 用户用 Backspace 修正 → underline 恢复默认色

示例：
  标准答案：yesterday
  用户输入：y → e → s → u...（u 不匹配 yesterday[3]）
  → underline 变红，但不中断输入
  用户按 Backspace 删除 u → 输入 yes...
  → underline 恢复
```

#### 3.6.5 输入框音效

| 事件 | 音效 | 说明 |
|---|---|---|
| 键盘按下 | 清脆机械键盘声（短，50ms） | 可关闭或调节音量 |
| 词确认正确 | 叮～短音（100ms） | 可关闭 |
| 词确认错误 | 低沉咚（80ms） | 可关闭 |
| Perfect 整句 | 三连叮～ | 可关闭 |

> 音效设计原则：克制、不扰民。默认开启但音量适中。提供独立音量滑块。

### 3.8 Main Area — 判分反馈层（整句完成后）

#### 3.8.1 三层反馈

整句最后一个词确认后，触发判分反馈：

| 判分 | 条件 | 动画 | 音效 | 显示时长 |
|---|---|---|---|---|
| **⭐ Perfect** | 所有词一次正确 | 绿色描边整句闪一下（200ms）→ 中央飘出「Perfect! +10」→ 分数跳动 | 三连叮 | 800ms |
| **👍 Good** | 1-2 词自行纠正后正确 | 蓝色描边闪过 → 中央飘出「Good +6」→ 分数跳动 | 单叮 | 800ms |
| **💪 Keep trying** | 超时或 >2 词错误 | 橙色描边闪过 → 显示正确答案渐显 → 「Keep trying +2」 | 低沉咚 | 1.5s（显示答案） |

#### 3.8.2 反馈层设计细节

```
反馈文字动画：
  Perfect：「⭐ Perfect!」从中央弹出，scale 0→1.1→1，然后 +10 从右侧飞入分数数字
  Good：「👍 Good」从中央弹出，+6 飞入
  Keep trying：「💪 Keep trying」从中央弹出，+2 飞入，同时正确答案在输入位置渐显

反馈层不遮挡用户视线：
  - 反馈出现在当前输入区上方 40px 处
  - 反馈结束后自动消失（不卡流程）
  - 反馈期间用户无法操作（仅 800ms-1.5s 的片刻）
```

#### 3.8.3 Keep trying 时的正确答案展示

```
原输入区替换为正确答案展示：
┌──────────────────────────────────────────┐
│  went [你的输入: go]  ← 红色标注          │
│  bought [你的输入: buyed] ← 红色标注      │
└──────────────────────────────────────────┘

显示 1.5s 后自动过渡到下一句。
用户可提前按 Space 跳过展示。
```

### 3.9 Main Area — 逐词渐变揭示模式（句乐部核心 Feature，TypeNow 采纳）

> **句乐部的杀手级 Feature：Progressive Sentence Building。**
> 句子不是一次性给全，而是逐词递进揭示。每个新增的词自然重复了前面所有词。

#### 3.9.1 模式说明

TypeNow 提供两种模式，用户可在设置中切换：

| 模式 | 说明 | 默认 |
|---|---|---|
| **逐词揭示**（推荐） | 中文分步显示，每完成一个词揭示下一个 | ✅ 默认 |
| **全文展示** | 中文一次显示完整句子 | 备选 |

#### 3.9.2 逐词揭示规则

```
中文句子：我昨天去超市买了些蔬菜
英文对照：I / yesterday / went / to the supermarket / and bought / some vegetables

揭示节奏：
Step 1：中文显示「我  ___  ___  ___  ___  ___」
       用户输入 → I
Step 2：中文显示「我 昨天  ___  ___  ___  ___」
       用户输入 → yesterday
Step 3：中文显示「我 昨天 去  ___  ___  ___」
       用户输入 → went
...以此类推

每次揭示时：
- 新出现的中文词有微淡入动画（150ms）
- 已完成的中文词保持显示但颜色变淡（#94A3B8）
- 当前待翻译的中文词保持突出颜色（#1E293B / #F1F5F9）
```

#### 3.9.3 中文对照布局

```
逐词揭示模式下的中文显示：

┌──────────────────────────────────────────────────┐
│  我    昨天    去    超市    买了    些蔬菜        │
│  I     ___    ___    ___     ___     ___         │
│  已完成  当前   未揭示   未揭示   未揭示   未揭示    │
└──────────────────────────────────────────────────┘

每个中文词：
- 已完成：灰色，底部有对应英文
- 当前：高亮，底部高亮输入区
- 未揭示：浅灰，#CBD5E1，无底部内容
```

### 3.11 Main Area — 句乐部特色容错机制（差异化增强）

> **句乐部的缺口：纯规则判分僵硬，同义表达不同就判错。TypeNow 可以做得更好。**

#### 3.11.1 预置同义词库

```
每个词位预置 1-3 个同义表达：

例：went → {went, gone, traveled} ×（gone 不是过去式，不收录）
    supermarket → {supermarket, store, grocery store, market}
    bought → {bought, purchased, picked up, got}
    vegetables → {vegetables, veggies, greens, produce}
```

同义词匹配的得分规则：
- 标准答案：10 分
- 预置同义词：10 分（同等对待）
- 不在库中但语法正确：标记为「可收录」→ 管理员审核后入库

#### 3.11.2 容错范围

| 错误类型 | 是否容错 | 扣分规则 |
|---|---|---|
| 大小写（I/i, 首字母） | ✅ 容错 | 不扣分（设置可关闭） |
| 单复数（apple/apples） | ⚠️ 部分容错 | 标记黄线，不扣分但提示 |
| 时态错误（go/went） | ❌ 不容错 | 算错误 |
| 拼写错误（yestaday） | ❌ 不容错 | 算错误 |
| 多余空格 | ✅ 自动 trim | 不扣分 |
| 标点遗漏 | ✅ 容错 | 不扣分但补全 |

## 四、状态流转

### 4.1 完整生命周期

```
进入 /practice
    ↓
[初始化] 加载句子队列（正常 + 复习混入）、加载用户偏好设置
    ↓
[就绪] 显示第一句中文 → 等待用户输入
    ↓
[练习循环]
    ↓  用户逐词输入
    ↓  每个词：匹配 → 反馈 → 确认
    ↓  整句完成：判分 → 反馈 → 0.5s → 下一句
    ↓  或用户按 Esc：跳过 → 显示答案 → 0.5s → 下一句
    ↓
[本轮结束] 达到本轮设定句数（≥10 句）
    ↓
[过渡] 0.5s → 自动跳转 /practice/result
    ↓
    ├─ 显示本轮总结
    ├─ 更新 review_queue
    └─ 提供 AI 强化入口
```

### 4.2 暂停/恢复

```
暂停触发：
  - 点击 ⏸ 按钮
  - 窗口失焦（设置可开关，默认关闭）
  - 长按 Space 1 秒

暂停状态：
  - Main Area 模糊遮罩
  - Bottom Bar 灰色
  - 键盘焦点保留
  - 按 Space 或点击遮罩 → 恢复

恢复时：
  - 当前词输入保留（不丢失）
  - 遮罩淡出（200ms）
```

### 4.3 退出确认

```
退出触发：
  - 点击 ← 返回
  - 按 Esc（当不在输入中时）
  - 浏览器关闭/刷新（beforeunload 拦截）

确认弹窗：
  ┌──────────────────────────────────────┐
```

## 八、错误处理 & 边界情况

### 8.1 网络断开

```
检测：请求失败 / navigator.onLine === false
表现：
  - 练习本身不依赖网络（句子已加载），可继续做题
  - 提交记录失败时：本地暂存（IndexedDB），网络恢复后自动提交
  - 顶部出现黄色提示条：「网络连接中断，结果将在恢复后自动保存」
```

### 8.2 刷新/关闭

```
beforeunload 事件：
  if 本轮已做题数 > 0 && 未结束：
    浏览器默认拦截：「你有未保存的进度」
    不自定义提示（Chrome 已不支持自定义文案）

  if 本轮已做题数 === 0 或 已结束：
    不拦截
```

### 8.3 空输入确认

```
用户按 Space 但当前词输入为空：
  → 不确认为空词
  → 输入框闪烁（红色 underline 闪一下）
  → 不消耗任何分数
```

### 8.4 连击数超大

```
连击数 > 999：
  → 显示「999+」，不继续递增数字
  → 实际值仍然记录（用于成就）
```

### 8.5 TTS 不可用

```
Web Speech API 不可用：
  → Ctrl+R 和点击发音降级为静默
  → Bottom Bar 中的 🔊 图标变灰并加删除线
  → 不弹错误提示（静默降级）
```
