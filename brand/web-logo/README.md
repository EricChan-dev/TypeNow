# 网站 Logo 资产（喵学社）

由豆包生成的 7 张原图派生的全套网站 logo 资产。原始水印已去除，AIGC 元数据未带出。

```
brand/web-logo/
├── tools/build-web-logo.py      # 主构建：7 原图 → 去水印/抠图/图标（可重跑）
├── tools/build-brand-lockup.py  # 品牌锁标：真实字体排版合成（依赖主构建的 color.png）
├── tools/fonts/                 # 站酷快乐体（OFL 1.1，可随仓库分发）+ 许可全文
├── source/                      # 去水印 + 抠图后的变体原图（*-ai.png 为 AI 原版留档）
├── png/                         # 网站各尺寸产物
├── favicon.ico                  # 16/32/48 三合一
├── preview.html                 # 自包含预览页（双击即开，图全内联）
└── preview-lockup.html          # 品牌锁标预览页（新旧对比 + 字体对比）
```

重新生成：

```bash
python3 brand/web-logo/tools/build-web-logo.py              # 默认读 ~/Downloads
SRC_DIR=/path/to/dir python3 brand/web-logo/tools/build-web-logo.py
python3 brand/web-logo/tools/build-brand-lockup.py          # 需先跑上一条；WAVE=0 关闭逐字跳动
```

依赖：仅 Pillow + numpy（系统 python3 自带），无新增依赖。

## 7 个变体的角色

原图文件名（`生成猫碗换书的logo*.png`）与内容的对应关系，是靠调色板 + 墨迹
分布测出来的（见下表）。构建脚本里的 `ROLES` 字典就是这个映射，换图需同步改。

| 原图后缀 | source/ 产物 | 内容 | 处理方式 |
|---|---|---|---|
| （无编号） | `color.png` | 彩色版：猫头 + 摊开的书，无文字 | 泛洪抠透明底 |
| `(1)` | `line.png` | 线条版：黑线白底 | 保留底色 |
| `(2)` | `line-reverse-bg.png` | 反白线条透明背景版：白线灰底 | 亮度键控 |
| `(3)` | `line-reverse.png` | 反白线条版：白线深底 | 保留底色 |
| `(4)` | `line-bg.png` | 线条透明背景版：黑线白底 | 亮度键控 |
| `(5)`/`(6)` | — | AI 原版锁标不再使用（原因见下节），留档 `brand-*-ai.png` | 排版合成替代 |

注意：原图全部是 RGB 无透明通道（豆包把「透明背景版」压平到了纯色底），
真 alpha 是在这里重建的。

## 水印怎么去的

7 张原图右下角都有同一枚独立水印横带（1536 高图实测 y1452–1506 / x1263–1501；
2688×896 那张 y847–878 / x2529–2667），与正文之间隔着大片空白。去法是
**整带切除，不做修补**：

1. 算内容 bbox 时把「水印区」（x ≥ 75%w 且 y ≥ 90%h）从墨迹掩码剔除；
2. 裁切框下缘硬性钳位在 90%h —— 比水印带起点（94.5%h）还低 4.5%，
   数学上保证水印像素进不了画面。

不采用 inpaint 修补：在干净纯色底上修补必留涂抹痕迹，切除则零痕迹。

## 品牌锁标：为什么改用排版合成（不再抠 AI 原图）

`(5)`/`(6)` 两张 AI 原图曾按泛洪抠取，但有两个硬伤：

1. **水印带与文字带同色**（都是深藏青）。横向版水印带 y847–878 与最右字簇的
   x 区间重叠，任何按颜色/亮度的键控都无法只删水印留文字；裁切钳位虽能挡住
   水印，但纵向版文字带下方同样被污染过。
2. **AI 生成的字体不可控**：笔画边缘发虚、字重不匀，放大就糊。

因此锁标改为 **真实字体排版合成**（`build-brand-lockup.py`）：徽标取去水印
彩色版 `color.png`，文字矢量渲染，放大不糊、颜色精确。

- **文案考证**：对原 (5) 文字带做逐字位图结构分析——左「口」+ 右上「艹」+
  右下「田」= 喵；宽横盖「冖」+ 下「子」= 学；左「礻」+ 右「土」= 社。
  确认为 **喵学社**（注：CLAUDE.md 里的「句学社」为旧称）。
- **字体**：站酷快乐体（ZCOOL KuaiLe Regular）。选型原因：唯一可获得的
  「俏皮」向中文开源字体（OFL 1.1，可随仓库再分发，全文在
  `tools/fonts/OFL-KuaiLe.txt`）；系统与 WPS 内嵌的 CJK 字体全为正体
  （黑体/宋体/楷体/旗黑），无圆体娃娃体。
- **文字色** `(0,23,60)`：取自原图文字带实测中位数 (0,19,55) / (1,27,65)。
- **俏皮处理**：逐字交替微倾 ±4° + 上下起伏 3%（3 倍超采样后缩小，
  边缘平滑）。`WAVE=0` 可关。
- **比例**：纵向 字高/徽标高 0.46、间距 0.14（实测自原 (5)：305/669、92/669）；
  横向 字高 0.70、间距 0.12（原 (6) 的 0.78 因其徽标更扁而偏大，按现徽标调小）。
- **留档**：AI 原版抠图保留在 `source/brand-vertical-ai.png`、
  `source/brand-horizontal-ai.png`，预览页可新旧对比。

## 产物清单与用途

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `favicon.ico` | 16/32/48 | 浏览器标签页（Next.js 约定放 `src/app/favicon.ico`） |
| `png/apple-touch-icon.png` | 180 | iOS 添加到主屏（白底实底，iOS 对透明合成不可预测） |
| `png/icon-{16…512}.png` | 11 档 | PWA / 各处通用（`png/icon-192.png` + `icon-512.png` 是 PWA manifest 主力） |
| `png/icon-maskable-{192,512}.png` | 2 档 | Android 自适应图标（白底 + 72% 安全区，防裁圆切边） |
| `png/brand-horizontal-{48,96,192,512}.png` | 4 档 | 导航栏 / 页脚横排锁标（按高度给） |
| `png/brand-vertical-{128,256,512}.png` | 3 档 | 启动页 / 竖排场景 |
| `png/line*-512.png` | 4 档 | 线条系 512 备用（站点当前用不到更小的） |

## 质量核验记录（程序化测量，非目测）

- 5 个抠图 source：四角 α=0（`line`/`line-reverse` 是保底色版，四角 α=255 属预期）；
  底部 4 行全透明，水印带未进入画面。
- 亮度键控修复复核：`line-bg` 1231×813 / `line-reverse-bg` 1233×810，
  文字/徽标 bbox 不再被亮度键控下的水印文本撑大（曾膨胀至 1389×1035）。
- 品牌锁标（排版合成版）：纵向 1329×1399——徽标带 y[79,832]、文字带 y[982,1347]、
  3 字簇齐全，逐字顶部错落 +18/0/+35px（跳动生效），文字主色 median RGB
  恰为 (0,23,60)，四角 α=0；横向 3155×895——徽标/文字垂直中心 447/449 基本居中。
  旧 AI 版留档 `source/brand-*-ai.png`。
- `favicon.ico` 内嵌 16/32/48 三档。
- maskable-192：中央亮部 81.6% / 暗部 9.4%，深蓝图形在白底上对比清晰。
- 16/32px 下彩色版退化为近似剪影（细节并成色块，两只眼睛仍可辨）。
  彩色版适合 ≥48px；标签页图标若要更强辨识度，后续可做极简单色版
  （只取猫头轮廓），当前尺寸链已够用。
