## 四、关键设计决策

- **不合并课时**（用户 m23194 否决 merge-lessons 预览）：保持 1:1 导入结构，靠扩句增厚
- **402 直接中断**：余额不足时脚本立即停止并提示，不空转刷失败
- **429/5xx 指数退避 3 次**：并发下限速自动重试
- **失败不写库**：结构/分段 0 成分不写；待补条件天然续跑，重跑无副作用
- **扩句去重**：库内 26.1 万句 norm 后全局去重，避免与原句/跨课时重复
