## 登录方式

| 方式 | 说明 | 技术实现 |
|------|------|---------|
| **微信扫码登录** | 用户用微信扫描页面二维码 → 微信内确认 → 自动登录 | 微信开放平台网页应用接入 |
| **手机号验证码登录** | 用户输入手机号 → 获取短信验证码 → 验证登录 | 阿里云短信 / 腾讯云短信服务 |

## 设计要点

| 维度 | 规范 |
|------|------|
| **布局** | 左右分栏，左侧 45%~50% 展示品牌视觉，右侧 50%~55% 为登录功能区 |
| **左侧内容** | 精美英语学习插画 + 产品 Slogan「码上一小句，人生一大步」 |
| **左侧色调** | 品牌深蓝底 + 白色文字，与产品整体风格统一 |
| **右侧登录区** | 简洁白色卡片，主次分明，手机号区号默认 +86 |
| **返回首页** | 页面左上角「← 返回首页」按钮 |
| **响应式（≤768px）** | 左侧图片隐藏，只显示右侧登录区，全宽居中 |
| **验证码按钮** | 发送后 60 秒冷却，防止重复发送 |
| **新用户** | 手机号首次登录自动注册，无需单独注册页，降低流失 |
