# 写作练习 `/strengthen/write`

> AI 生成写作主题，用户自由英文写作（3-15 句），AI 逐句批改。

---

## 功能说明

| 项目 | 说明 |
|------|------|
| **AI 做什么** | 生成一个写作主题，要求用特定句型/词汇 |
| **形式** | 自由英文写作（3-15 句） |
| **批改** | AI 逐句批改：语法纠错 + 地道表达 + 正向反馈 |
| **输出** | 结构化批改报告，可分享 |

---

## 技术要点

- 1 次 API 调用（主题生成 + 批改合并）
- 批改输出 JSON：{ corrected, errors[], highlights[], tips[] }
- 成本：≈ ¥0.03/次

---

## 路由

| 路由 | 说明 |
|------|------|
| `/strengthen/write` | AI 写作练习 |
| `/write/report` | 批改报告详情页 |
