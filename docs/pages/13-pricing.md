## 年度会员优惠

```
¥29/月 × 12 = ¥348/年
¥199/年 ÷ 12 = ¥16.6/月

年度会员相当于 5.7 折，立省 ¥149。
引导用户在月度会员和年度会员之间对比，突出年度优惠。
```

## 付费转化路径

```
普通会员使用路径：
  打字练习（每天，养成习惯）
  → 智能复习积累错误（感知到价值：「我真记住了」）
  → AI 强化每周 2 次用完（不够用，想要更多）
  → 场景只有 2 个（想解锁职场/影视内容）
  → ¥29？一杯咖啡而已 → 升级月度会员
  → 月度会员续费时，提示年度会员更划算 → 升级年度会员
```
