## 设计规范

| 维度 | 规范 |
|------|------|
| **整体风格** | 默认深色主题，克制专业。背景色一深一浅交替区分模块（`#0F172A` / `#1E293B`） |
| **主题切换** | 导航栏右上角提供深色/浅色切换按钮，默认深色 |
| **Hero 区** | 居中排版，大号 Slogan（56px bold，单行不换行），深色表面背景 |
| **CTA 按钮** | 主按钮使用琥珀色（`#F59E0B` + 白色文字），次按钮使用描边样式 |
| **导航按钮** | 登录为琥珀色按钮（主 CTA），免费开始为文字链接（次操作） |
| **排版节奏** | 各模块左右布局为主，文字左栏 + 可视化右栏 |
| **定价** | 仅提供免费和月度会员两种版本，简单透明 |
| **产品截图** | Layer 3 使用产品 mockup 展示 AI 出题界面 |
| **用户评价** | 使用真实职业+真实场景+量化结果的三段式证言 |
| **响应式** | 移动端各模块垂直堆叠，Hero 区 Slogan 缩小至 24px |
| **文案原则** | 聚焦用户提升和益处，避免留存/引流/获客等业务术语 |

## 与旧版差异

| 旧版内容 | 新版变更 | 原因 |
|---------|---------|------|
| 白色背景为主 | 默认深色主题，深/浅交替 | 产品调性升级，深色更专业 |
| 功能特点 4 卡 + 三层架构 | 整合为 Layer 1→2→3 递进叙事 | 减少冗余，层层深入 |
| 产品截图 2 张 | 内嵌到 Layer 1/3 的左右布局中 | 图文结合更直观 |
| PRO 版 + 团队版 | 仅免费 + 月度会员 2 档 | 简化定价 |
| 底部 CTA 多条信任信息 | 精简为单按钮 | 减少信息噪音 |
| 导航栏「产品特性」 | 改为「首页」 | 语义更清晰 |
| Logo「TypeNow」 | 改为「TypeNow·码上英语」 | 品牌升级 |
| 登录为文字链接 | 登录改为琥珀按钮，免费开始改为文字链接 | 优先级调整 |
| Hero Slogan 换行 | 改为单行 | 视觉更有力 |
