# 练习结果页 `/practice/result`

> 用户完成一轮练习（≥10 句）后展示。同时是 **AI 强化训练的入口**。

---

## 页面布局

```
┌─────────────────────────────────────────┐
│  🎯 本轮练习总结                          │
│                                          │
│  18 句中：Perfect 12 · Good 4 · 加油 2     │
│                                          │
│  📋 你的薄弱点                             │
│  ┌─────────────────────────────────────┐ │
│  │ • 过去时态 — 出现 2 次错误            │ │
│  │ • 冠词遗漏 — 出现 1 次               │ │
│  │ • suggest 用法 — 出现 1 次            │ │
│  └─────────────────────────────────────┘ │
│                                          │
│  💡 针对薄弱点来一次强化训练？              │
│                                          │
│  [ 出题练习 ]  [ 场景对话 ]  [ 写一段 ]     │
│  [ 跳过，下次再说 ]                        │
└─────────────────────────────────────────┘
```

---

## 薄弱点分析

综合本轮练习错误，由 AI 一次性分析（1 次 API 调用），输出薄弱点列表。

---

## 强化入口

用户可从三种 AI 强化形式中自选：
- **出题练习** → `/strengthen/quiz`
- **场景对话** → `/strengthen/chat`
- **写一段** → `/strengthen/write`

---

## 路由

| 路由 | 说明 |
|------|------|
| `/practice/result` | 练习完成后自动跳转 |
