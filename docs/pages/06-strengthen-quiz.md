# AI 出题练习 `/strengthen/quiz`

> AI 基于用户的薄弱点，生成 5 道针对性中译英题目。

---

## 功能说明

| 项目 | 说明 |
|------|------|
| **AI 做什么** | 基于用户的薄弱点，生成 5 道针对性中译英题目 |
| **形式** | 和正常打字练习一样，但题目围绕特定语法点 |
| **反馈** | 打完 5 题后显示对错和解析 |
| **用户感知** | 「这是为我定制的题目，专治我的短板」 |

---

## 技术要点

- 与薄弱点分析合并为 1 次 API 调用
- 题目格式与正常练习一致，复用 `/practice` 的打字组件
- 成本：≈ ¥0.03/次（GPT-4o-mini）
