# 打字练习页 `/practice`

> **核心页面。Layer 1：用户花时间最多的页面。**

---

## 练习流程

```
步骤 1：用户选择场景（或直接开始）
    ↓
步骤 2：显示中文句子
    ├─ 例：「我昨天去超市买了些蔬菜」
    └─ 显示词数提示（8 words）
    ↓
步骤 3：用户逐词敲击英文
    ├─ 输入框只显示当前词
    ├─ 已完成的词在前面一字排开（绿色）
    └─ 空格键确认当前词 → 进入下一词
    ↓
步骤 4：整句完成 → 总评
    ├─ 全部正确 → ⭐ Perfect +10 分
    ├─ 少量纠错 → 👍 Good +6 分
    └─ 多次错误 → 💪 Keep trying +2 分
    ↓
步骤 5：自动过渡到下一句（0.5 秒延迟）
    └─ 键盘焦点保持，无需鼠标操作
```

---

## 判分规则（纯规则，零 AI 成本）

| 判分 | 条件 | 判定逻辑 |
|------|------|---------|
| **Perfect** | 完全匹配标准答案 或 预置同义表达 | 预设词库匹配（如 "store" 可替代 "shop"） |
| **Good** | 1-2 处小错误但自行纠正 | 用户第一次输错 → Backspace 修正 → 最终正确 |
| **Keep trying** | 超过 2 次错误或超时 | 显示正确答案，允许用户继续 |

---

## 反馈设计

| 反馈 | 动画 |
|------|------|
| Perfect | 绿色描边闪一下（200ms），不震动 |
| Good | 蓝色描边闪过 |
| Keep trying | 橙色描边 + 正确答案渐显 |
| 连击数字 | 右上角显示数字，无火焰特效 |
| 音效 | 清脆短音（正确）/ 低沉短音（错误），可关闭 |
| 分数动画 | 数字平滑跳动，不弹窗 |

## 键盘操作

| 操作 | 方式 | 设计意图 |
|------|------|---------|
| 确认当前词 | 空格 | 自然，习惯 |
| 修正上一个词 | Backspace | 回到上一词位，不删已确认内容 |
| 跳过当前句 | Esc | 不弹确认框，直接跳过 |
| 句子过渡 | 自动（0.5s 延迟） | 减少操作打断 |
| 暂停/继续 | 顶部暂停按钮 | 非高频操作，用鼠标即可 |

## 练习页界面状态

### 状态一：输入前 / 正在输入（完成前）

中文在上、英文在下，**均为白色字体，字号偏大**。英文以占位符形式展示，下划线数量 = 词数，逗号句号直接显示。

```
┌─────────────────────────────────────────┐
│                                         │
│         我昨天去超市买了些蔬菜             │  ← 中文白色，24-28px
│                                         │
│   I  yesterday  ___  ___  ___  ___ .    │  ← 英文占位，20-24px
│             ┌──────────────┐            │
│             │    went      │ ← 当前输入  │
│             └──────────────┘            │
│                                         │
└─────────────────────────────────────────┘
```

**规则：**
- 中文始终在上方，白色字体，字号 24-28px
- 英文占位在下方，白色字体，20-24px，每个词用下划线占位 `___`，已确认词替换占位符
- 标点符号（逗号、句号）直接显示在对应位置，不占词位
- 当前输入词居中显示，带蓝色输入下划线
- **完成前不显示音标、释义、语法结构**
- 中英文字号整体偏大，突出句子核心

### 状态二：全部完成（完成后）

**上下翻转**：英文在上（大字 + 每个词独立词性背景色），中文在下。音标下方显示词性分类标签。

```
┌─────────────────────────────────────────┐
│                                         │
│     /aɪ ˈjestərdeɪ went tuː ðə .../    │  ← 读音（整句音标，14px）
│  ┌─代词──┐┌──状语──┐┌─动词─┐┌介词┐...  │  ← 词性标签行（12px）
│  ┌──────┐┌────────┐┌────┐┌──┐┌───┐   │
│  │  I   ││yesterday││went││to││the│   │  ← 英文大字（22-26px）
│  │ 绿底 ││  蓝底   ││红底││灰││灰 │   │     每个词独立背景色
│  └──────┘└────────┘└────┘└──┘└───┘   │
│  ┌──────────┐┌────┐┌─────┐┌──────┐   │
│  │supermarket││and ││bought││some  │   │
│  │   橙底    ││灰底││ 红底 ││灰底  │   │
│  └──────────┘└────┘└─────┘└──────┘   │
│  ┌──────────┐                         │
│  │vegetables│                         │
│  │   橙底   │                         │
│  └──────────┘                         │
│                                         │
│       我昨天去超市买了些蔬菜               │  ← 中文（18px，次要色）
│                                         │
│           [ 📖 句子解析 ]                │  ← 解析按钮
│                                         │
└─────────────────────────────────────────┘
```

**规则：**
- 读音在英文上方，整句音标，浅灰色 14px
- 词性标签行在读音下方、英文上方，12px，每个标签居中对应下方单词
- 英文大字 22-26px，每个词独立卡片：
  - 半透明背景色按词性区分（10 种词性各有专属色）
  - 文字色也按词性对应
  - padding 4-8px，圆角 4px
  - 自动换行排列
- 中文在下方，18px，次要文字色
- 句子解析按钮在中文下方
- 反馈浮层叠加在英文区域上方
- 中英文字号整体偏大，英文比中文更大

### 反馈浮层

判分反馈叠加在完成态英文卡片上方，居中显示。

| 判分 | 图标 | 文案 | 颜色 |
|------|------|------|------|
| **Perfect** | ✨ sparkles | Perfect! +10 | `#22C55E` |
| **Good** | 👍 thumbs-up | Good +6 | `#3B82F6` |
| **Keep trying** | 💪 arm | Keep trying +2 | `#F59E0B` |

样式：半透明深色底 `#0F172AE6`，圆角 14px，居中排列 icon + 文字。

### 词性颜色方案

| 词性 | 中文标签 | 背景色 | 文字色 |
|------|---------|--------|--------|
| 主语/名词 | 主语 | `#065F4620` | `#34D399` |
| 谓语/动词 | 谓语 | `#7F1D1D20` | `#F87171` |
| 宾语/名词短语 | 宾语 | `#7C2D1220` | `#FB923C` |
| 状语/副词 | 状语 | `#1E3A5F20` | `#60A5FA` |
| 代词 | 代词 | `#164E6320` | `#22D3EE` |
| 助词/助动词 | 助词 | `#713F1220` | `#FBBF24` |
| 冠词/限定词 | 冠词 | `#33415540` | `#9CA3AF` |
| 介词 | 介词 | `#33415530` | `#9CA3AF` |
| 连词 | 连词 | `#33415530` | `#9CA3AF` |
| 定语/形容词 | 定语 | `#4C1D9520` | `#A78BFA` |

> **原则：每种词性有独立的半透明背景色和文字色。完成后英文句子的每个词按词性着色，形成一目了然的结构可视化。**

### 辅助信息显示规则

| 元素 | 完成前 | 完成后 | 位置 |
|------|:--:|:--:|------|
| 中文句子 | ✅ | ✅ | 完成前上方，完成后下方 |
| 英文句子 | ✅（占位+已填） | ✅（完整大字） | 完成前下方，完成后上方 |
| 读音（音标） | ❌ | ✅ | 英文上方 |
| 主谓宾分析 | ❌ | ✅ | 英文下方 |
| 句子解析按钮 | ❌ | ✅ | 中文下方 |
| 词性着色 | ❌ | ✅ | 仅完成后显示 |
| 标点符号 | ✅ | ✅ | 始终可见 |

> **设计原则：完成前 = 极简（仅中文 + 英文占位，全白色），完成后 = 学习（翻转展示 + 读音 + 主谓宾 + 解析）。中间区域只放句子，其他信息全放顶栏和底栏。**
