# 分享卡片系统 `/share/card`

> 用户完成里程碑时触发生成分享卡片，促进社交传播。

---

## 触发场景

| 场景 | 卡片内容 | 分享文案模板 |
|------|---------|------------|
| 连续 10 次 Perfect | 连击数 + 等级徽章 | 「今天手感不错，连续 10 句 Perfect 🔥」 |
| 等级晋升 | 新旧等级对比 + 累计练习数 | 「在 TypeNow 升到黄金段位了！」 |
| AI 写作批改完成 | 原文 vs 批改后 对比 | 「我写的英语 vs AI 改完的，差别好大」 |
| 每周学习报告 | 本周练习数 / 征服错误数 / 写作数 | 「这周征服了 8 个语法错误」 |

---

## 卡片设计规范

| 维度 | 规范 |
|------|------|
| **尺寸** | 1200×630（OG Image 标准，适配社交平台） |
| **品牌元素** | TypeNow Logo + typenow.cn |
| **配色** | 深蓝底 + 白色文字 + 金色点缀 |
| **生成方式** | Next.js API Route 动态生成，Vercel Edge Cache |

---

| 路由 | 说明 |
|------|------|
| `/share/card` | 分享卡片落地页，SEO 优化 |
