### 页面模块背景交替规则

着陆页各模块背景色一深一浅交替：
- 深色模块：`#0F172A`
- 浅色模块：`#1E293B`

形成视觉节奏，避免大片同色造成的沉闷感。

## 反馈设计（克制版）

| 反馈 | 动画 |
|------|------|
| Perfect | 绿色描边闪一下（200ms），不震动 |
| Good | 蓝色描边闪过 |
| 错误 | 橙色描边 + 正确答案渐显 |
| 连击数字 | 右上角显示数字，无火焰特效 |
| 音效 | 清脆短音（正确）/ 低沉短音（错误），可关闭 |
| 分数动画 | 数字平滑跳动，不弹窗 |
