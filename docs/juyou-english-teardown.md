## 〇、结论摘要

1. **"模式一样"只对了一半。** 分销结构（会员档 + 一级直推 + 首单/续费佣金）确实一样；
   但它最显眼的那一环 —— **付 ¥699 才能拿推广佣金** —— 恰好是我们 2026-09-29 刚拆掉的那一环。
   它跑了半年多不等于它这一环变合法，只说明还没被看到。
2. **它真正比我们成熟的地方不在分销结构，在三件事**：提现体验、价格阶梯、上新与调佣的发布节奏。
   这三件都不涉及合规风险，且成本可控。
3. **我们的真实瓶颈不是分销模式。** 2026-10-01 生产库：
   27 个账号 / **0 个被邀请人** / 6 个练过一句 / 78% 注册后零练习 / 2 笔测试支付。
   在这个激活率上照抄它的佣金比例，放大器放大的只会是流失。

## 一、它是什么（事实清单）

### 1.1 权益档位与价格

| | 畅学版 | 合伙人版 |
|---|---|---|
| 定位 | 不限时长，适合深度学习 | 终身畅享 + 推广分佣 |
| 价格 | 月 ¥29 / 季 ¥79 / 年 ¥199 | **第一批 ¥599（首批限量 500）→ 第二批 ¥699（限量）→ 原价 ¥1999** |
| 学习权限 | 练习不限时、背单词全开、高级 AI 语音引擎、AI 口语评测 100 次/日 | 同上 + AI 口语评测不限 |
| 推广返利 | 无 | 有 |
| 支持 | 无 | 推广素材 + 主播培训资料 + 合伙人专属社群 + 1V1 专属客服 |

价格阶梯这条要注意：它**不是一口价**，而是"首批 599 → 第二批 699 → 原价 1999"。
699 这个数字与我方终身档的原价 699 相同（[pricing.ts:102](../src/lib/pricing.ts#L102)）。
它靠"限量批次"给自己留了一个自动涨价的机制。

### 1.2 佣金与提现

| | 句游英语 | TypeNow（现状） |
|---|---|---|
| 推终身/合伙人档 | **50%**（699 → ¥349.5） | 50%（[partner-rules.ts:37](../src/lib/partner-rules.ts#L37)） |
| 推会员/畅学版 | 首单 **60%** / 续费 **40%**（10/1 起，原 50%/30%） | 首单 50% / 续费 30%（不分档） |
| 结算 | **佣金当日结算** | 成交后 **15 天冷静期**（[partner-rules.ts:25](../src/lib/partner-rules.ts#L25)） |
| 提现 | 无手续费、5 点前提现当天到账、支付宝 | 微信商家转账、门槛 ¥50、**只允许全额提现**（[withdraw/route.ts:111](../src/app/api/partner/withdraw/route.ts#L111)） |
| 归因 | 专属链接 + **专属 4 位数字数据号邀请码** + 客服反向追溯 | 8 位字母数字 `inviteCode`（[subscription.ts:30](../src/lib/subscription.ts#L30)） |

它的提现记录截图里 4 笔全部「已打款」，收款方式是**支付宝** —— 不需要绑微信。

### 1.3 产品（来自推广视频里的真实界面，不是宣传语）

左侧导航：主页 / 我的课程 / 课程市场 / 课本同步 / 课程向导 / **错题库** / 背单词 / 查单词 / 音标·语法 / 会员权益 / 合伙人招募 / 推广返利。

| 面 | 它的事实 |
|---|---|
| 课程市场 | "**420+ 课程覆盖全年龄段**"，幼儿启蒙 → 高中；Power Up / Reading for Comprehension / Little Fox / 新概念；自称"10 万+ 精选句子语料库" |
| 课本文本同步 | **203 门**课程，按年级（一年～高三）× 版本（人教版 PEP / 外研社 / 译林 / 北师大 / 沪教 / 重大 / 川教 …） |
| 2026-09-30 上线 | 国际音标、**指法跟练**、英语 16 时态全景 |
| 信任背书 | 视频里专门一屏放营业执照、ICP 备案、国际域名证书、**增值电信业务经营许可证**，字幕"正规企业 资质齐全" |

**读法**：它的护城河是**内容覆盖度**（年级 × 版本 × 出版社），不是某一个功能。
其中"指法跟练"与我方"中译英逐词敲击"是同一块肌肉记忆 —— 它在把这一层吸收进一个更宽的产品。
这一条我们不跟（一个人无法复制内容军备竞赛），但要在 PRD 与素材话术里明确差异：**我们卖的不是"有 420 门课"，是"练了会记住"。**

## 二、不能抄的三条

### 2.1 付费用取得推广资格（最重要的一条）

它的合伙人版 = **终身权益 + 佣金资格**，且素材直接写"推广合伙人 699，佣金 50% 即 349.5"。
这正是《禁止传销条例》第七条(二)"交纳费用取得推广资格"的构成表述。

我们走过同一条路：旧 ¥399 合伙人被判为命中要件（[distribution-compliance.md](distribution-compliance.md) §3），
并在 2026-09-29 完成准入解绑 —— 现在提现的门禁是**免费同意《推广合作协议》**（`partner_agreed_at`），
不是付费（[withdraw/route.ts:25](../src/app/api/partner/withdraw/route.ts#L25)）。

**结论：不要因为它在跑就把这一环装回来。** 监管的处置路径是先送风险警示书、督促关停分销，
而不是先罚款；它没出事只说明还没被看到。这一环一旦被要求关停，代价是**前期推广员全部失效、已发佣金面临追缴**。

### 2.2 把"赚钱"当卖点

它的权益对比表里，合伙人列有一多半是"推广范围 / 佣金收益 / 专属支持"，
素材字幕是"终身学习自由副业天花板""边学边赚"。
这正是 [promotion-launch-checklist.md](promotion-launch-checklist.md) §二 那句判断：
**经营对象从"卖课"变成"卖赚钱机会"，与层级深浅、佣金多少都无关。**
对比表的排版本身不要抄。

### 2.3 把"提现无手续费"当卖点

它的素材把"提现无手续费"当成一条卖点反复强调。
但我们自己的 [compliance-archive-audit.md](compliance-archive-audit.md) 已经查出同一个问题的另一半：
协议承诺依法代扣代缴，实现却是**佣金全额转出、无任何扣缴**。
一句"无手续费"很可能等于"平台没有履行扣缴义务"。这是扣缴义务的转嫁，不是福利。
**在扣缴口径（实现扣缴 or 收回协议口径）落地前，我们不要在这个方向上跟它比。**

## 三、可借鉴的六条（按优先级）

### 3.1 提现体验：让"我的钱能拿到"变成零摩擦（改动最小，优先级最高）

它的承诺是"5 点前提现当天到账、无手续费"。
我们的硬伤不在到账时效，而在 [withdraw/route.ts:111](../src/app/api/partner/withdraw/route.ts#L111) 的
`PARTIAL_NOT_ALLOWED`：赚到 ¥249.5 就必须**一次提完**，不能留 ¥100。
月卡一单佣金只有 ¥14.5（[promotion-launch-checklist.md](promotion-launch-checklist.md) §六），
要攒 4 单才够 ¥50 门槛 —— 然后还被要求全额提走。

这是实现细节带来的产品硬伤，也是推广员最容易得出"这平台在卡我钱"的一秒。
**抄法**：允许部分提现（沿用现有 `FOR UPDATE` 按行占用的实现，只放宽金额校验），
并把到账时效写成**兑现得了的**承诺（做到当天就写当天，做不到就写 T+1）。

### 3.2 价格阶梯 + 限量：给自己的档位一个自动退场机制

它用"首批 599 → 第二批 699 → 原价 1999"完成了一次不需要解释的涨价。
而 [business-model.md](business-model.md) §4.1 早就写过：终身档"现在保留并卖，
但用「限量」给它一个自动退场机制" —— 这条至今没执行。

**抄法**：作为先例，它证明"限量批次"是可用的；前提是限量必须**真实**。
管"虚构原价"的那条法条同样管"限量"（[pricing.ts:1](../src/lib/pricing.ts#L1) 的整段注释就是为此写的）。

### 3.3 佣金分档（不是抄数字，是抄机制）

它 10/1 把**推畅学版的佣金**从首单 50%/续费 30% 提到 **60%/40%**，推合伙人版维持 50% ——
而且这是**永久改比例**（成本永久化）。

我们的答案自己早写好了：[business-model.md](business-model.md) §4.2 建议
**月 50% / 年 35% / 终身固定 ¥100**，§10.2 第 7 条至今挂着"☐ 待拍板"。

它的账正好印证这条建议：素材写明 699×50% = **¥349.5 当日结算**，
而终身档的成本是逐月发生的（AI 用量、课程服务）——**把未来成本贴现到现在付掉**。
收入明细截图里那 4 笔 `+299.50`（699 之前第一批 599×50%）就是同一回事。

**抄法**：拍掉 §10.2 #7 这个板；若要跟它的高比例，用**限时窗口**（上新周/节庆首单 60%），
而不是永久抬。参数进 [partner-rules.ts](../src/lib/partner-rules.ts) 单一来源。

### 3.4 "上新 + 调佣"同日发布（最被低估的一条）

它 9/30 一条群公告同时给了三样东西：

1. **新功能**：音标、指法、16 时态上线，并写明入口（【音标/语法】→【国际音标、16 时态学习】；【背单词】→ 切换指法跟练模式）
2. **新收益**：10/1 起佣金调整（推合伙人 50% 不变；推普通会员首单 60%、续费 40%）
3. **情绪**：提前祝国庆快乐

推广员拿到的是"今天就能发的弹药"。我们产品一直在更新（最近的发音评测一串提交），
但**从未把一次发版翻译成推广员能用的素材**，而 checklist 阶段 0 还要求公域完全不提推广。

**抄法**：建立一个无代码的固定动作 —— 每次发版产出
(a) 3 条可改写素材骨架 (b) 一句"这次更新解决了用户哪个抱怨" (c) 价格/佣金是否有变。
素材库已有 `version` / `publishedAt`（[promotion-materials.ts](../src/lib/promotion-materials.ts)），是现成载体。

### 3.5 可口播的短码

它是"专属链接 + **专属 4 位数字数据号邀请码** + 客服反向追溯"。
专属链接解决微信私域，4 位数字码解决**直播口播**（链接点不动、二维码进不去，观众只能听一串数字）。

我们的 `inviteCode` 是 8 位大写字母数字（[subscription.ts:30](../src/lib/subscription.ts#L30)，已去掉易混字符），
链接场景够用，但口播报不出来。而直播正是它主要的成交场景。

**抄法**：不动现有 `inviteCode`（会断链），另加一个独立的 4 位数字**渠道/数据号**，
专用于口播、客服与订单归因。[business-model.md](business-model.md) 里"渠道账号的 inviteCode 当渠道码（零开发量）"
是它的临时版本，可以升级成正式短码。

### 3.6 信任背书前置

它专门用一屏放营业执照 / ICP 备案 / 域名证书 / 增值电信业务经营许可证，配字幕"正规企业 资质齐全"。
这解决的是推广员最真实的顾虑：**我推的东西会不会明天就跑路。**
我们的清单里第 1 条是律师审协议（[promotion-launch-checklist.md](promotion-launch-checklist.md) §一），
但"资质可见"这一层在推广中心里目前没有。

**抄法**：把**真实存在**的资质（ICP 备案、营业执照、域名）做成推广中心与价格页上可引用的一屏。
⚠️ 只放真实有的；没有增值电信业务经营许可证就不要出现这一项
—— 这属于虚假宣传，性质比"漏放"严重。

## 四、素材形态的取舍：成品 vs 骨架

它给推广员的是**成品**：视频叠字幕（"终身合伙人现价 699""佣金 50% 即 349.5 元""佣金支持日结 提现无手续费"）、
成品海报、"海量宣传素材包"，甚至"主播培训资料"和"直播陪跑"。
我们刻意给的是**可改写的骨架** + 禁用词单测（[promotion-materials.ts](../src/lib/promotion-materials.ts)、
[promotion-materials.test.ts](../src/__tests__/promotion-materials.test.ts)），理由是：
一条文案被 10 个人一字不改地转发，朋友一眼看出是广告，平台也会判成低质营销。

这个取舍不是二选一：

- **成品图/视频**（品牌物料、资质屏、功能演示）——降低门槛，适合能力弱的推广员与公域 **不涉及链接** 的场景
- **骨架文案**（私域一对一、朋友圈）——保留推广员与其朋友之间**独有的信任**，也是平台内容风控上的安全区

它的"喂成品"路线能跑通，前提是它有一批主播型推广员；
我们的种子是活跃用户，不是主播（[promotion-launch-checklist.md](promotion-launch-checklist.md) §三）。
所以：**成品物料可以补，但不要把骨架文案的主线换成成品转发。**

## 七、如果只做三件事

1. **提现**：允许部分提现 + 写一个兑现得了的到账时效（顺手把"还差 ¥X 可提现"的提示口径对齐）
2. **拍板佣金分档**（[business-model.md](business-model.md) §10.2 #7），并把"限时上调"做成
   [partner-rules.ts](../src/lib/partner-rules.ts) 里的单一来源，而不是永久抬比例
3. **建立"发版 → 推广员弹药包"的固定动作**（模板 + 素材库版本号，零代码）

第 1 件决定推广员信不信我们，第 2 件决定他赚不赚得到钱，第 3 件决定他有没有东西可发。
它半年做出来的"成熟感"主要来自这三条，不是 699 那个档。

> ⚠️ 顺序约束不变：在律师看过《用户协议》《推广合作协议》《隐私政策》之前，
> 不要在公域公开招募推广员（[promotion-launch-checklist.md](promotion-launch-checklist.md) §一）。
> 看到对手在跑不构成提前放量的理由。
