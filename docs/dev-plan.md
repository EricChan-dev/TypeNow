# 30 天开发计划

---

## 里程碑总览

| 阶段 | 天数 | 目标 | 交付物 |
|------|------|------|------|
| **P0 骨架** | D1-3 | 项目搭建 + 基础框架 | Next.js + Supabase + 部署上线 |
| **P1 打字核心** | D4-10 | 打字练习可用 | 逐词敲击 + 判分 + 场景选择 + 句子库 |
| **P2 智能复习** | D11-15 | 复习系统上线 | 错误收集 + 艾宾浩斯调度 + 复习混入 |
| **P3 AI 强化** | D16-22 | AI 功能可用 | 薄弱点分析 + 出题 + 场景对话 + 写作批改 |
| **P4 用户系统** | D23-25 | 完整用户体系 | 注册/登录 + 统计 + 等级 + 成就 |
| **P5 分享+打磨** | D26-28 | 传播能力 | 分享卡片 + 移动适配 + PRO 付费墙 |
| **P6 发布** | D29-30 | 正式上线 | 最终测试 + 自媒体内容 + 正式发布 |

## 每日任务

### P0：项目骨架（D1-3）

| 天 | 任务 |
|---|------|
| D1 | `create-next-app` + TypeScript + Tailwind + ESLint 配置；Supabase 项目创建；基础布局组件 |
| D2 | 微信开放平台接入 + 短信验证码服务集成；登录页面（左侧图片+slogan，右侧登录表单）；「返回首页」按钮；中间件保护路由 |
| D3 | 数据库建表；Vercel 部署；域名 typenow.cn 配置；CI/CD 跑通 |

### P1：打字核心（D4-10）

| 天 | 任务 |
|---|------|
| D4 | Practice 页面布局；中文展示 + 输入区 UI |
| D5 | 逐词敲击逻辑：空格确认词、词校验、已完成词展示 |
| D6 | 整句判分逻辑（规则词库）；Perfect/Good/Keep trying 反馈动画 |
| D7 | 场景选择 UI；分类筛选；句子数据入库（320 句） |
| D8 | 练习结果页：分数/连击/本轮总结 |
| D9 | 键盘优化：回车/ESC/自动过渡；连击系统 + 等级系统 |
| D10 | 音效集成；本地存储草稿（防止刷新丢失）；P1 联调 |

### P2：智能复习（D11-15）

| 天 | 任务 |
|---|------|
| D11 | review_queue 表设计；错误收集触发器；复习题目混入练习 |
| D12 | 艾宾浩斯间隔调度逻辑；next_review_at 计算 |
| D13 | 复习标记 UI（🔁 角标）；连续正确毕业逻辑 |
| D14 | 复习统计面板（待复习/已征服/准确率） |
| D15 | P2 联调 |

### P3：AI 强化（D16-22）

| 天 | 任务 |
|---|------|

| D19 | 场景对话页：AI 对话 UI + 纠错逻辑 |

## 成功指标（MVP 阶段）

| 指标 | 目标 | 衡量方式 |
|------|------|---------|
| 核心功能可用 | P0-P5 无阻断 Bug | 端到端测试通过 |
| 自己愿意用 | 连续使用 7 天 | 自己打卡记录 |
| 种子用户 | 50 人注册 | 自媒体引流 + 朋友圈 |
| 次日留存 | > 30% | Supabase 数据查询 |
| 分享卡片生成 | > 20 次 | 卡片 API 调用日志 |
| 首次付费 | 1 人 | 自己/朋友付费测试 |
