## 一、法律依据（三条，够用）

### 1. 《禁止传销条例》（国务院令第444号，2005-11-01 施行）第七条

> **（一）**组织者或者经营者通过发展人员，要求被发展人员发展其他人员加入，对发展的人员
> 以其**直接或者间接滚动发展的人员数量**为依据计算和给付报酬，牟取非法利益的；
>
> **（二）**组织者或者经营者通过发展人员，要求被发展人员**交纳费用或者以认购商品等方式
> 变相交纳费用，取得加入或者发展其他人员加入的资格**，牟取非法利益的；
>
> **（三）**组织者或者经营者通过发展人员，要求被发展人员发展其他人员加入，**形成上下线关系，
> 并以下线的销售业绩为依据**计算和给付上线报酬，牟取非法利益的。

第（二）项的宾语是关键：交钱买到的是 **"加入或者发展其他人员加入的资格"**。
**消费者花钱买服务**不在其列，**花钱买推广资格**才在其列。

### 2. 2013 年两高一部《关于办理组织领导传销活动刑事案件适用法律若干问题的意见》第 5 条

> 以销售商品为目的、**以销售业绩为计酬依据**的单纯的"团队计酬"式传销活动，**不作为犯罪处理**；
> 形式上采取"团队计酬"方式，但实质上属于**"以发展人员的数量作为计酬或者返利依据"**的
> 传销活动，以组织、领导传销活动罪定罪处罚。

**这条划出了最核心的那根线：按"销售额"给钱，还是按"人头数"给钱。**

### 3. 最高检《"四维一体"治理电商平台"团队计酬"式传销》（2026-09-11）

给出的穿透式审查抓手是三项：**是否缴纳入门费、经营对象、人员收入来源**。

它同时明确了两侧边界：

- **正向（安全区）**：对坚持 **单层直推、真实商品流通、无变相入会门槛** 的平台予以正向宣传引导，
  推广**合法单层裂变式营销**。
- **高危特征**：层级超过三级且跨层级计提收益；新会员提成占总收益主要比例；**变相入门费**；
  人头奖励；与下线人数挂钩的团队分红；以囤货、购买礼包作为解锁多层计酬的条件；
  将溢价道具商品作为入会载体；宣传"零风险""一年回本"。

**并且要注意风险分级**——它列出了"尚未构成犯罪也会被处理"的档位：

> 对于存在变相入门费、人头计酬，资金异常流转，但**尚未形成 30 人以上传销组织**的，
> 由市场监管部门送达风险警示书，**督促平台紧急关停分销功能**。

也就是说：**即使不构成犯罪，你的分销体系也可能被直接叫停**——那意味着前期投放的推广员全部失效、
已发出的佣金面临追缴。这是本文件存在的真正理由，而不是"会不会坐牢"。

### 所以：必须改，但它是"跟随性改动"，绝对不能只改文案

**只改文案有两个后果，一个是没用，一个是有害：**

- **没用**：最高检明确写的是**穿透式审查**——"围绕是否缴纳入门费、经营对象、人员收入来源
  等方面开展穿透式审查"。如果代码层面 `isPartner` 仍然门禁佣金，那实质没变，
  改文案只是**形式合规、实质不合规**。
- **有害**：实质没变而文本被改得"看起来很合规"，一旦被查，容易被认定为
  **明知法律要求而刻意规避**。这比文本直白更被动。

**正确顺序：**

```
① 先做准入解绑（改代码）→ ② 协议里的 4 处表述就变成事实错误，必须跟着改 → ③ 再改营销文案

## 三、唯一需要改的一处，以及改法

### 现在（危险）

```
¥399 合伙人  ─┬─→  终身 Pro            ← 这一半是合法商品
              └─→  取得推广资格         ← 这一半是「入门费」

¥399 商品    ──→  终身 Pro（纯消费，不再附赠推广资格）

免费注册     ──→  任何用户都能拿现金佣金（与 ¥399 完全无关）

### 为什么这是顺水推舟，而不是伤筋动骨

**你们 2026-09-26 的决策 3 已经做完了同一件事的一半：**

> 决策 3：邀请推广范围 —— **任何用户都可参与并获得会员天数**（参考句乐部）

当时解绑的是**天数制**那一半；**现金佣金那一半还锁在 ¥399 后面**。
把这一半也解绑，两条渠道口径就统一了，也不再需要"`partner` 套餐不发天数"
这类为了防叠加而生的例外规则（`membership-growth-plan.md` 第304-305行）。

**商业上也不吃亏：**

| | 付费加盟（哇学社式） | 免费加入（句乐部星火计划式） |
|---|---|---|
| 推广员基数 | 被 ¥1299/¥399 门槛筛掉绝大部分 | **全部注册用户** |
| 收入结构 | 早期收入里掺着"加盟费"，不可持续 | 只跟真实成交挂钩 |
| 合规 | 命中条例七(二) | **最高检明确的正向引导对象** |
| 风险 | 体系可能被一夜关停 | 基本无此风险 |

句乐部的星火计划就是**免费加入**，佣金照付（永久单 ¥500~600）。它甚至专门写文章攻击
哇学社"必须先付 ¥1299 才能推广"。**你的对手已经把合规结构示范给你了。**

## 四、安全区清单（可以直接照抄进《推广规则》）

1. ✅ **免费加入推广**——不收任何名义的入门费：加盟费、保证金、培训费、
   "购买指定礼包解锁"，**全部不行**
2. ✅ **只做单层直推**——A 推 B，A 拿佣金；**B 再推 C，A 不能再拿**
3. ✅ **按实际成交金额计佣**，绝不按"发展了几个人"计酬或返利
4. ✅ 佣金比例合理，且**不设"推荐满 N 人升级加价"的阶梯**
5. ✅ 有真实的教学服务交付（这是你们的天然优势）
6. ✅ 保留 90 天归因窗口与 15 天冷静期（比句乐部更保守，是资产）
7. ✅ 一旦退款/撤单，**对应佣金同步冲正**——佣金必须挂在"净成交"上

## 五、红线清单（任何一条都不要碰）

1. ❌ 付费才能成为推广者（**当前唯一命中项**，见第三节）
2. ❌ 多层级 / 跨层级计提 / 团队计酬（从下线团队的业绩里提成）
3. ❌ 按发展人数计酬，或设置"拉新奖励"
4. ❌ 以囤货、购买礼包作为解锁更高佣金的条件
5. ❌ 把溢价虚高的道具/虚拟商品当作入会载体
6. ❌ 收入主要来自新会员的加盟费而非教学服务销售
7. ❌ 宣传"零风险""一年回本""躺赚""月入过万"

**第 6 条是最本质的自检问题**：*如果某个月一个新用户都没进来，我的收入还有多少？*
如果答案接近零，说明收入来源不是教学服务——这是最高检文章里"庞氏资金特征"的判定思路。

## 六、另一类合规义务：税务报送与扣缴（与传销无关，但罚则很硬）

跑分销就必然要向个人付款，这会触发**独立的税务义务**。现行协议第六条第 2 项写的是：

> 佣金收入属于个人劳务或经营所得，您应依法向相关税务机关申报纳税。
> **平台不承担代扣代缴义务**，但如法规有强制要求，平台将配合执行。

这句话有两个问题：

**问题 1：「平台不承担代扣代缴义务」与现行法不一致。**

《个人所得税法》第九条：「以所得人为纳税人，**以支付所得的单位或者个人为扣缴义务人**。」
你向推广员支付的佣金属劳务报酬性质，**平台就是扣缴义务人**。这句免责声明不能对抗法定义务。

**问题 2：即使不谈扣缴，还有独立的「涉税信息报送」义务。**

[《互联网平台企业涉税信息报送规定》（国令第810号，2025-06-23 公布即施行）](https://www.gov.cn/zhengce/content/202506/content_7029052.htm)：

| 条款 | 要求 |
|---|---|
| 第二条 | 平台应报送平台内**经营者和从业人员的身份信息、收入信息**；"从业人员"指通过平台以个人名义**提供营利性服务的自然人**——付费推广的推广员正是这个定义 |
| 第四条 | 应于**季度终了的次月内**报送上季度收入信息 |
| 第十条 | 未按期报送、瞒报漏报、拒绝报送 → 责令限期改正；逾期不改处 **2 万~10 万**；情节严重责令停业整顿并处 **10 万~50 万** |
| 第十二条 | 本规定施行（2025-06-23）**之前**的涉税信息无需报送 |

配套还有税务总局 2025 年 7 月《关于互联网平台企业为平台内从业人员办理扣缴申报、代办申报若干事项的公告》。
**并且已经在查处**：2025 年 12 月税务总局公布了对网络交易平台涉税违法案件的查处。

**要做的三件事：**

1. **改掉协议里那句话**。不要再写"平台不承担代扣代缴义务"，改为如实约定扣缴与申报安排。
2. **在佣金结算流程里加税前处理**。提现走微信商家转账（协议第三条），
   需确认现在是按**佣金全额**转出的还是已做扣缴。
3. **建立季度报送能力**。需要能导出"推广员身份信息 + 上季度收入"的结构化数据。
   好消息：`partner_commissions` 已在记录 `partnerId` / `amount` / `availableAt`，
   **数据基础是有的**，缺的是导出与报送流程。

> **这一节的结论不依赖前面的传销分析**——即使你把分销做成完全合规的"单级 + 免费加入"，
> 这两项税务义务依然存在。

## 七、宣传话术禁用词（直播间/短视频/详情页）

最高检文中明确提到要在小程序、直播间设置敏感词拦截。以下词**不要出现在任何推广物料里**：

```
零风险 / 稳赚 / 躺赚 / 月入过万 / 一年回本 / 包赚
拉人头 / 发展下线 / 团队计酬 / 层级返利
加盟 / 代理费 / 门槛费 / 保证金
无限代 / 见点奖 / 对碰奖 / 直推奖
```

推广话术应当只描述：**推广者通过分享链接，按被推荐人真实付费金额获得佣金**。

## 八、上线前必须留档的证据

万一被约谈或检查，需要能证明"我的规则本身合规"。**建议现在就留存：**

| 留档物 | 为什么 |
|---|---|
| 《推广规则》完整版本（含生效日期） | 证明规则公开、无入门费 |
| 佣金计算结果与订单流水（可审计） | 证明按销售额、非按人头计酬 |
| 用户层级关系导出 | 证明只有一层，无上下线团队 |
| 推广物料的审核记录 | 证明未使用禁用词 |
| 退款与佣金冲正记录 | 证明佣金挂在净成交上 |

最高检文中把"对佣金与订单数据永久留存、以备审计"列为平台的应尽义务。
**数据留存不是麻烦，是最便宜的免责证据。**

## 九、什么时候需要复核本文件

出现以下任一情况，**在改代码之前**先回来读一遍并找律师：

- 要新增"推广员等级""团队奖励""多级返佣"
- 要把推广资格与任何付费商品绑定
- 要推出需要预存货款/购买礼包的分销模式
- 要在协议里承诺"永久""保底收益"
- 收到市场监管部门的约谈、风险警示书或平台投诉
