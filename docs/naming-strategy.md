### 2.1 事实（来自三家官网/官方文档，2026-09-30 抓取）

### 2.2 三个字的占领情况

| 字/词 | 谁在用 | 我们能不能用 |
|---|---|---|
| **玩 / 游戏 / 上瘾** | 三家全用 | ❌ 用了就是第四家游戏化，且做不过参考站的 SSS/PK/排行榜 |
| **社 / 部 / 俱乐部 / 社群** | 参考站、哇学社 | ❌ 撞社群感，且教育类"社"字带机构联想 |
| **句** | 参考站、句游 | ⚠️ 可以用，但**不能靠它承担信息量**，否则就是第四家"句子 App" |
| **肌肉记忆 / 手熟** | 句游英语**在功能页里讲了**，但没进名字 | ✅ **名字层是空的**（详见下） |
| **码** | —— | ❌ **我们现在的名字的真实问题**：口头说「码上英语」，听者第一反应是"代码/编程"，不是"打字"；「码上」的"马上"谐音只活在书面里 |

### 2.3 ⚠️ 对既有文档的两条修正

**(1) 「竞品无复习、无 AI」已经不成立。**

[strategy.md](strategy.md) §一 写竞品"无复习、无输出、无 AI 个性化"，
[juyou-english-teardown.md](juyou-english-teardown.md) §五 也把"参考站没有复习闭环"列为**未证实**。
本轮实测参考站官方文档的结论是：**它早就有，而且写得比我们更细**——

- 复习：动态调整间隔（"在你即将忘记的时候自动安排"）＋ 复习本 ＋ 生词本 ＋ 掌握列表
- AI：页面内 AI 助手（自动理解当前所学内容，每天 2 次免费）
- 还有：连击翻倍、C→SSS 评级、1v1 PK、排行榜、学习小组、成长热力图
- 六种模式：阅读 / 中译英 / 听写 / 听力 / 口语测评 / 视频观看

**含义**：① 对外话术里任何"竞品没有复习/AI"的表述必须删掉，否则一被用户对照就是硬伤。
② 我们的差异化不能再建立在"他们有缺口"上，只能建立在**做窄、做深**上
（[juyou-english-teardown.md](juyou-english-teardown.md) §1.3 那句"练了会记住"依然成立，但理由变了）。

**(2) 「肌肉记忆」不是我们的独占词。**

句游英语首页明写"肌腱记忆的深度建立""指尖敲击完整句子"。
但它把打字放在**三个模式之一**（拼图 / 打字 / 口语），
而打字是我们**唯一**的入口。所以这个词仍然是我们的，但理由要写成
**"他们是一个模式，我们是整个产品"**，而不是"只有我们提"。

### 2.4 结论：名字要押在"反方向"

竞品用两年把**「好玩 → 上瘾 → 打卡」**这条叙事讲透了。我们是新来的小团队，
在这条叙事里赢不了（他们有 70 万用户、SSS 评级、PK 房间）。
**唯一有效的命名方向是反着押：**

> 他们卖「像玩游戏」——你玩得开心，但没记住。
> 我们卖「**手熟**」——不好玩，但你敲过的句子真的留下了。

这个反方向还有个额外好处：**它和我们的产品事实一致**。
我们真正比别人硬的东西不是"更好玩"，是**每一句敲错都进遗忘曲线**，而且整个产品只为这一件事存在。

## 三、候选名字

### 方案 A ——「手熟」（首推）

- **名字**：手熟 / 手熟英语
- **出处**：欧阳修《卖油翁》——「无他，但手熟尔。」
- **slogan**：**敲过的句子，忘不掉。**

**为什么是它**

1. **零解释成本**。中文母语者几乎都听过这半句，一句古文就把"重复 → 熟练 → 记住"讲完，不用产品解释。
2. **正好是我们的机制**。手熟＝重复到不用想，这和"敲键盘 + 间隔重复"是同一件事，不是包装。
3. **占住竞品留出的空位**。参考站自己写"直到不用想就能打出来"、句游写"肌肉记忆"，
   **两家都在描述手熟，但都没有把它当名字**。这个位置是空的。
4. **对『句』零依赖，且是反游戏化立场**。名字里没有"玩"，天然把我们和三家区分开。
5. **可扩科**。将来做日语、韩语直接「手熟日语」，不用换品牌。

**风险与对策**

| 风险 | 对策 |
|---|---|
| 偏文言、不够潮 | 现代感交给英文名 TypeNow；落地页首屏用 slogan 补足 |
| 口语单说"手熟"略生硬 | 对用户统一说「手熟英语」，logo 是「手熟」两字 |
| 「手熟」可能让人想到"老手/熟练工"，显得劝退新手 | 首屏必须配一句破题：「不用基础，敲就完了」 |

---

### 方案 B ——「敲句」

- **名字**：敲句 / 敲句英语
- **slogan**：**打一句，记一句。**

**优点**：「敲」是竞品唯一没占的动作词（他们用"打""拼""拆"）；两字名口播成本最低；
「敲句」＝动作 + 内容，三秒内说清是干嘛的。

**风险（已从不建议升级为淘汰）**：子任务复核的商标近似规则显示，《商标法》第三十条的近似判定按
**发音、含义、视觉效果**比对，且**类似商品不限同一类别**（中国人大网释义）。
「参考站」「句游英语」已在**同一品类**占住「句」字语根，「敲句」落在同一语根上，
近似风险高于本文初稿的估计。**因此「敲句」不再作为退路**——
即使「手熟」检索不过，也应另起不含「句」的字，而不是退到这里。

### 方案 C ——「记得住」

- **名字**：记得住 / 记得住英语
- **slogan**：**练过的句子，自己会冒出来。**

**优点**：承诺最直白，正面回击竞品的"好玩但没记住"；口播顺。
**风险**：三个字，且**本身已经是广告语而非品牌标识**，商标显著性弱（可能被认为缺乏独创性）；
"记得住"是效果承诺，审查上比"忘不掉"更靠近《广告法》第二十四条的效果保证性承诺红线。
**作备选，不作首选。**

### 已淘汰的方案（连理由一起记下来，避免以后绕回去）

| 名字 | 淘汰理由 |
|---|---|
| 敲句 / 敲句英语 | 含「句」字，与参考站、句游英语同语根，商标近似风险不可控（详见上） |
| 敲学社 / 句乐营 / 句子派 | 直接撞参考站、哇学社的构词法，会被当成山寨 |
| 回锅英语 | 「回锅」有回锅肉与职场"回锅员工"的贬义联想 |
| 不哑英语 | 「不」字开头气势弱；"不哑"隐含"能开口"的效果承诺 |
| XX英语（任何） | 把"英语"当唯一定语，品类感弱且锁死扩科 |
| 码上英语（现名） | 「码」被读成代码/编程，与打字无关；见 §2.2 |

### 名字对比

|---|---|---|---|
| 口播顺口度（微信/直播） | ★★★★★ | ★★★★ | ★★★★★ |

## 四、Slogan 矩阵

**同一场景只用一个主力句**。多句并用等于没有 slogan。

### 1. 主 slogan（首屏、logo 锁配）

| # | 文案 | 打哪个点 | 风险 |
|---|---|---|---|
| 1 | **敲过的句子，忘不掉。** | 动作 → 结果 | 低。"忘不掉"是体验描述，非效果承诺 |
| 2 | **手熟，就记住了。** | 解释品牌名（微信简介/收银台用） | 低 |
| 3 | **打一句，记一句。** | 品类解释，短 | 低。与现有"打一句、记一句、学会一句"同源 |
| 4 | **不好玩，但记得住。** | 直接反定位竞品 | 中。有攻击性，适合传播物料，不适合协议/应用商店 |
| 5 | **无他，但手熟尔。** | 品牌典故 | 低。**仅用于品牌物料**，不能单独当价值主张（没说清品类） |

### 2. 痛点反打（小红书/朋友圈首句）

- 「练了一整年，还是不会说——**你缺的不是课，是敲。**」
- 「看中文，敲英文，一句敲三遍。**一周后它自己会冒出来。**」
- 「不是记不住，**是从来没把它用过一次**。」

### 3. 场景款（抖音口播/简介）

- 「每天十分钟，敲十句。」
- 「通勤敲两句，比背一页单词实在。」
- 「敲完自动进复习队列，不用自己安排。」

### 4. 邀约款（推广素材/分享卡）

- 「一起敲句子。」
- 「搜「手熟英语」，一起练。」
- 「我在手熟英语练了 N 句，这句我现在能直接说出来。」

### Slogan 合规红线

| 不要说 | 为什么 |
|---|---|
| 「七天搞定口语」「保证开口」「提分 XX」 | **《广告法》第二十四条**：教育培训广告不得对培训效果作明示或暗示的**保证性承诺** |
| 「最好的中译英打字工具」「第一」「国家级」 | **《广告法》第九条（三）**：不得使用"国家级""最高级""最佳"等用语 |
| 「永不遗忘」 | 绝对化且无法验证；「忘不掉」是体验描述，边界更安全 |
| 「掌握 10000 词」 | 与产品事实不符（我们练句子，不背词表） |
| 「名师命题」「XX 机构推荐」 | 《广告法》第二十四条禁止暗示考试机构/命题人员参与、利用机构或受益者形象作推荐证明 |

## 六、落地前必须核查的四道关卡（勿跳步）

> **顺序修正**：初稿写的是"先查商标，再定名，最后注册域名"，子任务按 CNNIC《域名争议解决办法》
> 复核后应当改为——**先占域名 + 同日递交商标**。理由：商标与域名互不自动授权，
> 而域名注册**满 2 年争议机构不再受理**，晚注册的风险不可逆；域名当天可完成，商标法定周期 12 个月起步。
> 完整查询入口与 SOP 见 [naming-availability-checklist.md](naming-availability-checklist.md)。

1. **商标检索**（中国商标网）：重点 **第 41 类**（教育培训）、**第 9 类**（App）、第 42 类、第 35 类。
   近似判定按**发音、含义、视觉效果**比对，且**类似商品不限同一类别** —— 这是淘汰「敲句」的依据。
   逐一查 `手熟` / `记得住`。
2. **域名实测**：`.com` / `.cn` / `.com.cn`（CNNIC WHOIS）。
3. **平台账号占用**：微信公众号（服务号名称唯一）、视频号、抖音、小红书、B 站、
   App Store / 华为 / 小米 / 应用宝。
4. **备案与资质**：见下。

### 6.1 备案侧硬约束（官方一手，已复核）

来源：[华为云 ICP 备案 FAQ「网站名称要求」](https://support.huaweicloud.com/icp_faq/icp_05_0116.html)（更新于 2025-03-07）：

| 约束 | 对本次换名的直接影响 |
|---|---|
| **网站名称要求三个字以上（含三个字）** | ⚠️ **「手熟」两个字不够，备案名称须填「手熟英语」**（四个字）。品牌视觉可以是「手熟」，备案与 App 名称用全称 |
| 不得以「中国/中央/国家/中华/人大/人民/反腐/纪检/监察/信访/维权/投诉」等字头命名 | 本方案不涉及 |
| 不能是纯数字、纯英文，不能含特殊符号 | 本方案不涉及 |
| 含「教育/出版/新闻/文化/广播影视」等字样须先向主管部门确认是否需前置审批 | ⚠️ **「手熟英语」不含"教育"，但落地页若出现"手熟教育"这类表述要走审批确认** |
| 个人备案：不能含公司/组织字眼，名称不宜使用简称（**至少 4 个汉字以上**） | 若以个人主体备案，规则更严；建议企业主体 |
| 各省管局另有禁止词（北京/河北/湖北/河南/湖南/内蒙古等禁「学院」；浙江禁「在线/社区」等） | 页面文案与 App 名称一并避开 |

**App 名称另有一套约束**：备案要求「应用名称不得和其他应用名称相同」，
且禁止商标术语、行业/职业/类别词堆砌、特殊符号与价格营销词。
即换名要**同时**满足备案 + 各应用商店 + 商标三套约束。

### 6.2 商标时间线（法定，不是经验值）

《商标法》第二十八、三十三条：商标局自收到申请起 **9 个月**内审查完毕并初步审定公告 →
公告起 **3 个月**异议期 → 期满无异议核准注册发证。**顺利约 12 个月。**

含义：拿证前只能用 ™，**不能开平台企业认证、不能用注册证做商标申诉或应用商店维权**。
所以推广侧的"品牌可信度"建设不能等商标——但也不能在拿证前宣称已注册（虚假宣传）。

> 本文不替代商标代理或律师意见。推广侧还须遵守

## 七、改名落地：代码与文案影响面

**当前最大的工程问题：品牌名没有单一事实源。** 「码上英语」在仓库里至少 16 处硬编码，
改名必然漏改——漏一处就出现新旧两个名字并存。

### 第一步（做在改名之前）：抽出品牌常量

新建 `src/lib/brand.ts`：

```ts
/** 品牌名的唯一事实源。改名只改这里；禁止在组件/素材/文案里再写死中文品牌名。 */
export const BRAND = {
  nameZh: "手熟",
  nameZhFull: "手熟英语",
```

### 第三步：协议类页面不能直接替换

已同意旧协议的用户，法律关系主体名称变更需要留痕。建议在新版协议加一句
「原『码上英语』自 YYYY-MM-DD 起更名为『手熟英语』，原协议项下权利义务由更名后主体继续履行」，
而不是把旧名字抹掉（抹掉会造成"这家公司是谁"的举证困难）。
**推广合作协议尤其重要**：推广员佣金请求权的依据在这份协议里，名称断链最容易引发纠纷。

### 第四步：顺带修掉的合规项

落地页有 3 处 `10,000+ 中国学习者`
（[page.tsx:128](../src/app/(public)/page.tsx#L128)、[:443](../src/app/(public)/page.tsx#L443)、[:611](../src/app/(public)/page.tsx#L611)），
与生产库真实规模（[juyou-english-teardown.md](juyou-english-teardown.md) §〇 记载：27 个账号）严重不符。
这与 §四 里"不要绝对化"是同一类风险，**改名物料上线时一并改为可验证表述或删掉**。
